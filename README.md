# Лабораторная работа №6 — ПИН/ПМ

Готовый проект: [MPSUlab67911/lab6](MPSUlab67911/lab6).

Работа объединяет тракт данных, интеграцию LSU и интеграцию прерываний (задания 7, 9 и 11 курса MPSU/APS).
По умолчанию в Vivado используется оригинальный тест `lab_11.tb_processor_system.sv` из MPSU/APS без изменений. Для частей 7 и 9 выбирается оригинальный `lab_07.tb_processor_system.sv`.
Индивидуальная программа — вариант 21: для входа `0x1230` результат `x10 = 6`.

Инструкции запуска Vivado, программы, ожидаемые результаты и описание проверок находятся в [README проекта](MPSUlab67911/lab6/README.md).

Для переноса на другой компьютер скачайте публичный репозиторий через **Code → Download ZIP** или клонируйте его по HTTPS. В клонированной папке обновления загружаются командой `git pull`.
